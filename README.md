# DharmaGates

Offre éditoriale web autour du zen Sōtō.

- `index.html` (français) et `en/index.html` (anglais) : accueil du site, deux portes « Pratiquer » et « Comprendre le zen Sōtō ». Générés par `outils/accueil-site.py` (le français fait foi, l'anglais en est traduit) ; styles dans `site.css`.
- `hannya-shingyo/` : outil pour apprendre à chanter l'Hannya Shingyō (Sutra du cœur), version bêta. Voir `hannya-shingyo/BETA-CHANGEMENTS.md`.

Site publié avec GitHub Pages depuis la branche `main`.
